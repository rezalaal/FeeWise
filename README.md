# FeeWise - School Fee Management System

FeeWise is a modern and efficient web application designed to simplify school fee management.  It provides a user-friendly interface for administrators, teachers, and parents to track, manage, and process fee payments.  This project is built using Laravel 11 for the backend and Svelte 5 for the frontend, leveraging the power of Inertia.js for seamless integration.
